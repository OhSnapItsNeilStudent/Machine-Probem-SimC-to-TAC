> Overview
The Parser is the second phase of our compiler project.  
It takes the list of tokens generated by the Scanner and builds a structured Abstract Syntax Tree (AST) that represents the syntactic structure of the source program.

The generated AST will serve as the input for the Intermediate Code Generator (ICG) in the next phase.

------------------------------------------------------------

> Input
The parser accepts a JSON-formatted list of tokens, usually stored in a file named sample_parser_in.txt.

Each token is represented as an object with two attributes:

type  → The token category (e.g., ID, INT, ASSIGN, WHILE)
value → The literal string value of the token (e.g., "x", "1", "=")

> Output
The parser outputs an Abstract Syntax Tree (AST) in JSON format, typically written to parser_output.txt.

The AST contains hierarchical nodes describing program constructs such as functions, assignments, conditionals, and loops.

Example Output:
{
    "type": "Program",
    "functions": [
        {
            "type": "FunctionDef",
            "name": "fact",
            "params": ["n"],
            "body": [
                {
                    "type": "Assignment",
                    "target": "f",
                    "value": {"type": "IntConst", "value": 1}
                },
                {
                    "type": "While",
                    "condition": {
                        "type": "BinaryOp",
                        "op": ">",
                        "left": {"type": "Var", "name": "n"},
                        "right": {"type": "IntConst", "value": 1}

                    "body": [
                        {
                            "type": "Assignment",

> How to Run
You can test the parser independently using main.py.

Command:
python3 main.py

------------------------------------------------------------

> Integration in the Main Compiler
In the full compiler pipeline, this module is called after the Scanner and before the Intermediate Code Generator (ICG).

Flow:
Source Code  →  Scanner  →  Parser  →  ICG

Sample integration snippet:
from parser import Parser

parser = Parser(token_list)
ast = parser.parse_program()

The variable "ast" will hold the Abstract Syntax Tree (a Python dictionary) that the ICG can then process.

------------------------------------------------------------

Notes
- Input must be valid JSON (double quotes only)
- Ensure tokens are complete and in the correct order as produced by the scanner
- The parser will stop or raise an error if it encounters unexpected tokens or malformed syntax
